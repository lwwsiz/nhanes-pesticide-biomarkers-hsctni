# Urinary pesticide biomarker co-exposure and a multi-assay hs-cTnI score

This repository contains the core reproducibility materials for a cross-sectional analysis of four urinary pesticide-related biomarkers and a three-assay high-sensitivity cardiac troponin I (hs-cTnI) score in two U.S. National Health and Nutrition Examination Survey (NHANES) cycles.

## Repository contents

- `data/analysis_dataset.csv.gz`: derived analytic dataset based on deidentified NHANES public-use records.
- `code/analysis_utils.py`: complex-survey regression and descriptive pooling utilities.
- `code/run_analysis.py`: primary cycle-specific models, survey-weight sensitivity analyses, sequential-adjustment models, and assay-specific analyses.
- `code/test_core_results.py`: automated checks for the principal numerical results.
- `code/expected_core_results.json`: frozen reference values for 19 core result rows.
- `code/test_guards.py`: invalid-input and numerical-boundary checks.
- `results/reproduced/`: outputs regenerated by the core-analysis script.
- `DATA_DICTIONARY.md`: definitions and coding for released variables.
- `DATA_NOTICE.md`: provenance, use, and redistribution notes.
- `ENVIRONMENT.md` and `requirements.txt`: software environment and dependencies.

Original NHANES transport files are not redistributed. Public source files and documentation are available from the [CDC NHANES website](https://wwwn.cdc.gov/nchs/nhanes/Default.aspx).

## Reproduce the core analyses

Create an isolated Python environment, install the dependencies, and run:

```powershell
python -m pip install -r requirements.txt
python code/run_analysis.py
python code/test_core_results.py
python code/test_guards.py
```

The analysis script writes regenerated outputs to `results/reproduced/`. All repository paths are relative, so the analysis can be run from any working directory.

The tests compare 19 core result rows against frozen, independently cross-checked reference values, including sample sizes, design degrees of freedom, standard errors, confidence intervals and P values. Input checks reject nonpositive or nonfinite survey weights and singleton-PSU strata rather than silently selecting a variance policy. Ordinary missing outcome/covariate values continue to use complete-case selection. These checks do not reconstruct scores from original NHANES transport files or reproduce all post-review analyses.

## Reproducibility scope

Starting from the supplied derived analytic dataset, the code reproduces the original cycle-specific primary models, descriptive inverse-variance pooled estimate, official-weight sensitivity analyses, sequential-adjustment Models 1–3, and assay-specific results. It reports their effect estimates, standard errors, confidence intervals and P values. Model 1 includes demographic adjustment and is not an unadjusted model. Cycle-specific inference uses the survey-design t distribution; the descriptive pooled row uses a normal approximation.

This release does not reconstruct analytic scores or sample selection from original NHANES files. It does not reproduce every manuscript table or figure, the subsequently added unadjusted model, or all post-review sensitivity analyses. The included tests validate the stated core scope, not these additional analyses.

The repository is intentionally limited to code required for the core numerical findings. Additional secondary-analysis and figure-generation code is available from the corresponding author upon reasonable request.

## Data and interpretation

The dataset contains only variables derived from deidentified NHANES public-use records. No restricted-use geography or linked-mortality data are included. The analysis is cross-sectional and should not be interpreted as establishing causality or effects of a specific parent pesticide.
